== 概述

《无尽的拉格朗日》AI战术推演中心是一个基于 RAG (Retrieval-Augmented Generation)
技术的专业战斗推演智能体系统。系统整合了169艘舰船的完整数据库、详细的战斗机制
资料库，并通过 DeepSeek 大模型提供 AI 驱动的战术分析，为玩家提供舰队搭配、
战斗策略、武器选择等全方位战术决策支持。

=== 核心功能

* *AI战术顾问* — 基于RAG技术的智能问答系统，可回答关于舰船搭配、
  战斗策略、武器选择等复杂战术问题
* *战斗模拟器* — 可视化编队搭建界面，AI分析对阵胜负概率，
  提供详细战术建议和改进方案
* *舰船百科全书* — 收录169艘舰船的完整数据，支持按类型、阵营、
  武器系统分类筛选和全文搜索
* *舰队优化器* — 基于数学优化模型的舰队组合推荐引擎，
  支持多目标优化（火力、生存、机动）
* *混合检索* — FAISS向量检索 + TF-IDF关键词匹配 + jieba分词，
  中英文混合检索策略

== 战斗引擎公式

=== 能量伤害

[stem]
++++
D_{energy} = D_{base} \times (1 + B_{damage} - T_{shield}) \times A_{tune} \times S_{strategy} \times C_{crit}
++++

=== 实弹/动能伤害

[stem]
++++
D_{kinetic} = \max(D_{base} \times (1 + B_{damage}) - T_{armor},\ D_{base} \times 0.10) \times A_{tune} \times P_{hit}
++++

=== 拦截机制

[stem]
++++
R_{intercept} = 1 - (1 - R_{self}) \times \prod_i(1 - R_{row,i}) \times \prod_j(1 - R_{global,j})
++++

=== 舰队总DPM评估

[stem]
++++
\text{DPM}_{fleet} = \sum_i (\text{DPM}_{ship,i} \times S_i(t))
++++

== 安装部署

=== 环境要求

* Python 3.10 ~ 3.12
* Node.js 18+ (舰船数据解析)
* Redis 7+ (可选，缓存加速)
* 2GB+ 磁盘空间

=== Docker 部署

[source,bash]
----
git clone https://github.com/lagrange-ai/tactical-center.git
cd tactical-center
cp .env.template .env
# 编辑 .env 填入 DeepSeek API Key
docker compose up -d
# 访问 http://localhost:3000
----

=== 手动安装

[source,bash]
----
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.template .env
node parse_ships.js lagrange_docs/lglrmax.html lagrange_docs/ship_database.json
python -c "from rag_service import build_vector_index; build_vector_index()"
python main.py
----

=== Kubernetes 部署

[source,bash]
----
kubectl create namespace lagrange
kubectl apply -f k8s/configmap.yaml
kubectl apply -f k8s/secret.yaml
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml
kubectl apply -f k8s/ingress.yaml
----
