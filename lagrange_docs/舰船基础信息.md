# 舰船基础信息

## 规则

- 服役数上限：指该舰船最多可建造的数量
- 超主力模块规则：M/A/B/C/D/E 等字母代表系统槽位，数字代表该槽位的模块编号。选了 M1 就不能选 M2，选了 B1 就不能选 B2
- 多方案共用服役上限：例如服役上限为 5，方案1（M1+B1+C2）造了 2 艘，方案2（M2+B3+A3+C2）造了 3 艘，2+3=5 到达上限
- "缝合"：出现此词可忽略服役上限
