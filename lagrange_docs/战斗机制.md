# 无尽拉格朗日 — 战斗机制

---

## 一、武器与伤害基础机制

### 1. 武器分类与攻击逻辑

**按弹道分类：**
- **直射武器**（轨道炮、脉冲炮、离子武器等）：攻击受敌方阵型阻挡，必须先清除前排舰船才能攻击中后排；不会被拦截
- **投射武器**（导弹、鱼雷等）：可无视敌方阵型直接攻击目标，但会被防空拦截降低伤害（风暴M2模块除外）

**按伤害类型分类：**
- **实弹伤害**：通过动能冲击或爆炸造成伤害，会被舰船装甲（物理护甲）抵消；大部分火炮、轨道炮、鱼雷属于此类
- **能量伤害**：通过高能粒子流造成伤害，无视厚重装甲，会被能量护盾抵消；离子炮、脉冲炮属于此类

### 2. 武器攻击流程（三个阶段）

1. **目标选择阶段**：战斗开始或目标被消灭后进入该阶段，依据敌方阵型和自身攻击序列锁定目标，选择时间为武器锁定时间，可在冷却阶段同时进行
2. **开火射击阶段**：锁定目标后进入该阶段，按攻击次数执行一轮攻击；若目标未被击毁则进入冷却阶段；若目标被击毁，立即中止开火，进入冷却和目标选择阶段
3. **冷却阶段**：每轮攻击后因过热或换弹进入该阶段，可同时进行目标选择

### 3. 武器命中率机制

- **轻型武器**：攻击小型舰船命中率更高，单发伤害低，难以对大型舰船造成有效伤害
- **重型武器**：攻击装甲厚重、机动性差的大型舰船效果更好，瞄准小型目标时命中率大幅降低

### 4. 攻击循环细节

- **锁定与冷却并行**：锁定同时进行冷却；锁定完成冷却未完成→继续冷却；冷却完成锁定未完成→继续锁定；目标已锁定过→无需再次锁定；开战第一轮攻击→不需要冷却
- **攻击持续**：完成锁定和冷却后进入攻击持续阶段，在攻击持续时间内均匀分批次输出。例：小米攻击持续16秒，攻击次数3×4 = 16秒内分4次攻击，每次打3发，每隔4秒攻击一次
- **目标死亡处理**：攻击过程中目标被击毁→不进入冷却，带着剩余攻击重新锁敌，打光剩余攻击后清空弹夹，重新进入冷却

## 二、舰船系统机制

### 1. 系统破坏与修复

| 系统 | 被破坏效果 | 维修次数 |
|------|-----------|---------|
| 主武器系统 | 无法攻击 | 战斗内自维修2次，第3次破坏后无法修复，战斗结束复原 |
| 舰载机库系统 | 舰载机无法起降；往复式返回后无法出击；独立式失去机库增幅 | 战斗内自维修2次，第3次破坏后无法修复 |
| 指挥系统 | 所有策略无法使用，只能常规输出 | 战斗内自维修3次，第3次维修后无法被再次锁定 |
| 动力系统 | 失去闪避能力，无法紧急避险脱离战斗 | 战斗内无法维修，仅战斗结束后可修复 |

- 每次动力系统被破坏都会扣除自身5%的血量；系统可恢复时需等待25秒，期间该系统的功能无效

## 三、舰载机与护航艇机制

### 1. 攻击模式（两种）

**独立作战：**
- 携带充足弹药，可在远离母舰的位置持续锁定目标攻击
- 执行战略打击时可以与目标纠缠作战
- 除开局在载机舰内进行首次锁敌外，其余时间可视为对方阵型内的护卫舰
- 攻击遵循"锁敌-攻击-冷却"循环，直到自身被击毁；锁敌时无视阵型阻挡
- 攻击流程：进入战斗—锁定—攻击—冷却—攻击—冷却…直至目标被消灭后才重新锁定

**往复打击：**
- 完成一次完整打击后返回载机舰船舱内补充弹药，再进行下一轮打击
- 完整流程：①舰载机在载机舱内根据武器锁敌速度初次锁敌并出舱 → ②按去程时间飞到对方阵营发起攻击 → ③攻击结束按返程时间返回 → ④在机库内等待冷却并锁定新目标（此阶段不会被防空武器锁定）→ ⑤冷却和锁定同时完成后再次出舱攻击
- 特殊机制：舰载机出舱后未完成攻击就丢失目标→在对方阵营内重新锁敌，而非返回载机舰
- 飞行途中冷却、锁定都可以进行

### 2. 舰载机加点作用

- **降低去程/返程时间**：增加往复打击的频率
- **选择目标时间下降**：往复式舰载机回到机库后，锁定目标时间需≤武器冷却时间才能再次出击
- **打击间隔缩短**：相当于降低攻击持续时间，增加输出频率
- **聚焦空战目标**：优先攻击对方战斗机和拦截机，降低对方空军对空能力，但无法第一时间攻击轰炸机

### 3. 轰炸距离与命中

- 轰炸距离用"吉米"表示
- 超过15吉米：每增加1吉米，所有舰载机命中额外衰减2%
- 低于15吉米：每靠近1吉米，命中额外增加2%
- 每1吉米舰载机飞行往复时间加2秒

## 四、防空机制

### 1. 反击防空

- **定义**：小范围防空机制，在受到舰载机攻击时触发，可攻击以自身或同排友方舰船为目标的敌方空中单位
- **生效逻辑**：敌方舰载机攻击我方舰船时，受击舰船和同排未被攻击的友方舰船会触发反击防空；防空武器根据索敌序列针对性防空
- **命中率**：舰载防空武器基础命中率15%，机载防空武器基础命中率60%

### 2. 区域防空

- **防空支援**：防空武器自带词条，可打击以同排友方舰船为目标的敌方空中目标，不会因自身受击改变攻击目标
- **周期性大范围防空**：通过加点获得，可让武器周期锁定临近排敌方战机或护航艇攻击，通常附加命中率提高或冷却降低效果；舰载防空武器命中率偏低，需优先加点命中
- **特殊防空舰船**：枪骑兵（防空范围扩展到全队）；圆锥综合（加点让同排防空武器扩大到临近排）

### 3. 主动防空

- **定义**：舰船或舰载机无需被攻击，即可自主锁定并攻击战场上任意位置的敌方空中单位，拥有更高锁敌优先级，可覆盖全场
- **对比**：被动防空需被攻击后才能反击，存在反应延迟；主动防空可先手打击，适合对抗轰炸机、飞机海
- **具有主动防空能力的单位**：米斯特拉（最强主动防空战机）、沙龙大气层拦截机、CVT800脉冲炮艇、狼蜥级防御护卫舰、锆石级突击护卫舰、刺水母防御护卫舰

### 4. 对空武器规则

- 对空武器分为**主动防空**和**被动防空**；被动防空分为**自身防空**（自己被舰载机攻击时反击）和**同排防空**（同排友方舰船受攻击时协助打击）
- 部分武器只能对空不能对舰，部分两者皆可

## 五、拦截机制

### 1. 拦截机制独立性

- 拦截机制与防空机制互相独立
- 不会因多队攻击降低拦截概率，也不会因防空压力大而失效
- 拦截是纯概率机制，加点命中、锁敌对拦截率无影响，只需点拦截相关加点

### 2. 拦截类型与生效范围

| 类型 | 说明 |
|------|------|
| 自身拦截 | 自身受到伤害时有概率拦截 |
| 同排拦截 | 同一排舰船受到伤害时有概率拦截 |
| 全局/全域拦截 | 全舰队所有船受到攻击时由该舰拦截 |

- 拦截范围只由初始防空范围决定，不受任何后天技能影响
- **光追级区域防空巡洋舰**：同排拦截；前突策略可扩大防空范围到全场，但拦截范围仍为同排
- **永恒风暴级（D2模块）**：高额自身拦截，无需额外拦截保护
- 拦截仅针对单轮攻击持续时间内攻击次数的数量（如一轮打了12发，每发都可能被拦截）

### 3. 拦截率计算

- **单艘舰船拦截率**：不同舰船不同，如雷火之星-B2单船拦截率27%，光追级防空型单船拦截率23%
- **多艘舰船拦截率**：`拦截率 = 1-(1-x)^n×(1-y)^m`（x、y为不同舰船拦截概率，n、m为对应舰船数量）
- **反拦截**：以百分比降低我方总拦截概率，如30%反拦截 → 实际拦截概率 ×(1-30%)
- **最终拦截**：`舰船总拦截 × (1-敌方反拦截)`

### 4. 被拦截后的最终伤害公式

```
被拦截后的最终伤害 = (1-全局拦截率)^a × (1-同排拦截率)^b × (1-自身拦截率)
```
（a = 队伍中有此全局拦截率的舰船数量；b = 舰队中有此同排拦截率且在此排的舰船数量）

## 六、伤害计算

### 1. 基础伤害计算公式

| 项目 | 公式 |
|------|------|
| 能量单发 | 基础伤害 ×(1+5%伤害加成-目标能量护盾)×(1+策略系数)+特殊单发 |
| 物理单发 | 基础伤害 ×(1+5%伤害加成)×(1+策略系数)-目标物理抵抗+特殊单发（最低10%保底） |
| 命中 | 基础命中 ×(1+命中加成-敌方闪避) |
| 最终冷却 | 基础冷却 ×(1-冷却加成)×(1-策略系数) |
| 锁定时间 | 基础锁定时间 ×(1-锁定减少+敌方锁定延长) |
| 最终暴击伤害 | 基础暴击伤害 ×(1+爆伤加成-敌方暴击伤害下降) |

### 2. 单发伤害公式（常用整理）

- **能量单发** = 基础伤害 ×(1+调校系数)×(1+伤害加成-目标能量护盾)×(1+策略系数)
- **物理单发** = 基础伤害 ×(1+调校系数)×(1+伤害加成-目标物理抵抗)×(1+策略系数)
- **暴击**：直接作用于最终单发伤害，不是初始伤害；暴击伤害是基础暴击伤害（"暴伤加成"）

### 3. 结构伤害公式

**舰船武器：**
- 实弹结构伤害 =（基础伤害+科技点增加伤害+策略增幅伤害）×(1+武器调校) - 对方护甲
- 能量结构伤害 =（基础伤害+科技点增加伤害+策略增幅伤害-基础伤害×对方护甲减伤%）×(1+武器调校)

**飞机/护航艇攻击结构：**
- 能量结构伤害 = [（基础伤害+科技点+载具加成）- 对方护甲] ×(1+武器调校)
- 实弹结构伤害 = [（基础伤害+科技点+载具加成+策略增幅）×(1+武器调校) - 对方护甲]

**不破防伤害（仅实弹存在）：**
- 破防判定：`（基础伤害+科技点+策略增幅×武器调校）- 对方护甲 > 0`
- 不破防时结构伤害 =（基础伤害+科技点+策略增幅）/10 ×(1+武器调校)

**可攻击系统武器打结构：**
- 结构伤害 =（基础伤害+科技点+策略增幅）×0.8×(1+武器调校) - 对方护甲
- 可攻击系统的武器打结构有系数，但不全是0.8，有些低于0.1（可能为BUG）

### 4. 系统伤害公式

**舰船武器：**
- 系统伤害 =（基础伤害+科技点+策略增幅）×(1+武器调校)×1.5
- 系统伤害系数不全是1.5且同一武器可变，目前测得系数有1.25、1.5、3

**飞机武器：**
- 武器调校与目标不一致：系统伤害 =（飞机基础伤害+科技点+载具加成）×系统伤害系数
- 武器调校与目标一致：系统伤害 = 飞机基础伤害 × 调校 × 系统伤害系数
- 常见系数：牛蛙/米斯特拉/小米=1.5；刺瑶=1.25或1.5；新大地=3（但武器加强不会提升系统伤害）

**暴击与策略：**
- 暴击伤害 = 系统伤害 ×(1+暴击系数×系统伤害系数)
- 策略伤害 = 系统伤害 ×(1+暴击系数×系统伤害系数)×策略伤害

### 5. 系统攻击效率

- 总发弹量 = Miss弹 + 命中弹；命中弹 = 结构伤害弹 + 系统伤害弹
- 当击毁一个系统视为一轮攻击结束
- **效率占比**：低效率≈命中20%、中效率≈命中40%、高效率≈命中60%
- 例：雷利亚特隐身型每分钟发弹20，武器命中率60%，命中12弹，其中系统 12×0.4=4.8，可能系统命中范围4~6发

### 6. 伤害计算实战修正（用户实测公式）

面板分钟伤害实际计算（以某武器为例）：
```
(单发基础伤害-抵抗伤害+强化提升) × 武器安装数 × 攻击轮次 × 每轮攻击次数 × 60 ÷ (持续时间+冷却时间)
```
例：(140-10+35)×2×1×4×60÷21 = 3771.4 → 向下取整3771，与面板一致（按这个来）

## 七、能量抗性与护甲机制

### 1. 能量抗性

- **定义**：即能量护盾，按基础伤害×最终伤害系数计算，最终伤害系数 = 1+总伤害加成-总抗性减免
- **伤害加成稀释**：抗性会被伤害加成稀释。例：70抗性的电磁59，面对总伤害加成50%的维塔斯B，实际免伤只有47%
- **抗性档位**：
  - 弱抗级：抗性30以下，大部分船属于此类，对能量输出几乎无抵抗力
  - 强抗级：抗性70-85（如电磁剑65、电磁59为70、双摇光套盾下的曲护85），面对飞机海实际免伤40%-50%
- 能量伤害被能量抗性限制：能量伤害×能量抗性%；若≥100%则无法造成伤害

### 2. 护甲机制

- 护甲主要抵消实弹伤害（物理护甲），重甲盾对实弹有强大统治力
- 能量伤害难以做到完美克制，基本靠结构值硬抗
- 实弹伤害 = 单发伤害 - 对面物理护甲值；若结果≤0则只有10%保底伤害
- 一点物理护甲 = 0.25%受维修加成，最高到150%

## 八、攻击循环与输出计算

### 1. 输出计算模型

- **一轮攻击伤害**：打多少发单发，每发考虑平均命中、暴击等的总和
- **一轮攻击时间**：锁定时间 + 冷却时间 - 冷却/策略等加成
- **秒平均伤害** = 一轮攻击的伤害 ÷ 一轮攻击需要的时间

### 2. 影响输出的关键因素

- **锁定**：对实战输出影响极大。目标越多、单体越小，消耗在转火、重新锁定上的时间越多，实际输出时间占比越少。所有输出船或母舰的减少锁定加点建议优先点满；后期空战甚至需要"超锁"（维塔斯B能降低80%锁定）。例：雷火锁定15秒，面板伤害12万，打4个1万血目标至少需1分半
- **冷却**：冷却短的优势主要体现在空战中。后期空战飞机血量低，基本被摸到就被击毁，冷却快一秒就能先秒杀对方，因此空战机冷却建议拉满。谷神是特例（前期使用，双方空战输出不足），其维修加点虽增加小米50%武器冷却，但小米攻击持续时间长，2秒冷却增加影响不大，反而10%维修提升大幅增加续航

### 3. 实战建议

- 优先点满减少锁定的加点，尤其是输出船和母舰
- 空战机优先拉满冷却加点
- 谷神在前期可选择维修加点提升续航
- 计算加点收益使用秒平均伤害模型

## 九、其他机制

### 1. 维修机制

- 维修量 = 在攻击持续时间内舰船面板维修量÷60×(100%+受维修加成%)
- 编辑数据包括：锁定维修目标的时间、维修目标的时间、每分钟维修量

### 2. 分伤机制

- 所有战斗都遵循分伤机制：舰队中所有可以攻击到敌方某类舰船的舰船，平均分摊伤害到这些船上
- 公式：（可被攻击的舰船 ÷ 2.5 取整）
- 例：舰船A/B/D可以攻击对面的舰船C/E，则它们按分摊攻击舰船C；即使舰船A攻击序列更丰富，也会照顾攻击序列没那么丰富的舰船B/D

### 3. 旗舰机制

- 每个舰队只能有一个舰船为全队提供旗舰效果
- 旗舰效果失效条件：舰船死亡，或旗舰对应的指挥系统在中途被损坏或被彻底摧毁

### 4. 人口限制

- 主舰队总人口上限500，增援舰船数量上限9艘

### 5. 航母机库加成

- 不同航母的机库对舰载机有不同加成
- 太阳鲸的舰船维护系统对整个航母所有机库都有加成
- 独立作战的护航艇收益最高的是冷却
- 带索敌的机库适合锁定时间长或对空的飞机（如海氏锁定时间长，适合进入有锁的机库）

### 6. 舰载机与母舰

- 如果搭载舰载机的母舰被摧毁，舰载机也会跟随母舰一起被摧毁

### 7. 伤害分类

| 分类维度 | 类型 |
|----------|------|
| 按伤害目标 | 结构伤害、系统伤害 |
| 按伤害类型 | 实弹伤害、能量伤害 |
| 按伤害效果 | 破防伤害、不破防伤害 |

- 目前破防和系统伤害的概念只存在于实弹伤害中
- 系统拥有独立的血量，不受物理护甲和能量护甲保护
- 只有特定标准的可以攻击某个系统的舰船才能攻击系统，其攻击系统的伤害跟对舰伤害一致
