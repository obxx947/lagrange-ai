## 1. 环境准备

### 必需软件
- **Windows 10/11** 操作系统
- **Python 3.10+**（[下载地址](https://www.python.org/downloads/)）
  - 安装时务必勾选「Add Python to PATH」
- **Git**（可选，用于版本管理）

### 验证 Python 安装
打开命令提示符（cmd）或 PowerShell，输入：
```bash
python --version
# 应显示类似：Python 3.10.x 或 3.11.x
```

## 4. 局域网访问

### 4.1 查询本机内网 IP
打开命令提示符，输入：
```bash
ipconfig
```

在输出中找到「IPv4 地址」，通常类似：
- `192.168.1.xxx`
- `192.168.0.xxx`
- `10.0.0.xxx`

### 4.2 局域网其他设备访问
确保所有设备连接**同一个 WiFi**，然后在其他设备的浏览器中输入：
```
http://192.168.1.xxx:3000
```
（替换为你的实际内网 IP）

> ⚠ 注意：Windows 防火墙可能会拦截外部访问，首次访问时请允许 Python 通过防火墙。

## 5. 桌面「质料」文件夹说明

### 5.1 文件夹位置
桌面新建文件夹，命名为：**质料**

### 5.2 支持的文档格式
- `.txt` — 纯文本文档
- `.md` — Markdown 文档
- `.pdf` — PDF 文档
- `.html` — HTML 文件（仅前端渲染，不参与向量检索）

### 5.3 自动过滤的文件
以下文件类型会被自动过滤，不会复制到项目：
- 可执行文件：`.exe`, `.dll`, `.msi`
- 压缩包：`.zip`, `.rar`, `.7z`, `.tar`, `.gz`
- 图片：`.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`
- 音视频：`.mp3`, `.mp4`, `.avi`
- 代码文件：`.py`, `.js`, `.ts`, `.java`, `.c`

### 5.4 使用流程
1. 将游戏攻略、战斗数据、配船心得等文本文档放入桌面「质料」文件夹
2. 启动程序（程序会自动同步到 `lagrange_docs` 文件夹并构建向量索引）
3. 修改/新增/删除文档后，调用向量库重建接口（见第10节）

## 6. 模拟器使用教程

### 6.1 舰队配队
1. 切换到「⚔ 舰队配队」标签页
2. 点击左侧五个舰队面板之一，选择要编辑的舰队
3. 在下方的舰船库中使用分类筛选或搜索找到目标舰船
4. 点击舰船卡片将其添加到当前舰队
5. 点击舰队面板中的舰船标签可移除

### 6.2 保存编队
1. 登录账号后，点击「💾 保存编队到云端」
2. 输入存档名称，点击确定
3. 编队数据将存入 SQLite 数据库，登录其他设备也可读取

### 6.3 读取存档
1. 点击「📂 读取存档」
2. 在弹出的存档列表中选择要加载的存档
3. 点击「读取」即可恢复编队配置

### 6.4 战斗模拟
1. 切换到「🔥 战斗模拟」标签页
2. 确认双方舰队已配置（在舰队配队页配置）
3. 调整模拟速度（1x-10x）
4. 点击「▶ 开始模拟」推演战斗
5. 点击「🤖 AI战术分析」获取AI增强战术评估

### 6.5 舰船图鉴
切换到「📚 舰船图鉴」浏览所有舰船的详细属性

## 7. 手机/其他电脑访问测试

### 7.1 前置条件
- 手机/其他电脑与服务器连接**同一 WiFi/局域网**
- 服务器端已启动（`python main.py`）
- 防火墙已允许 3000 端口

### 7.2 访问方法
1. 查询服务器内网 IP（`ipconfig`）
2. 在手机浏览器输入：`http://内网IP:3000`
3. 页面应正常显示，可注册/登录/对话/模拟

## 8. 定时清理配置

5. 操作选择「启动程序」
6. 浏览选择 `deploy\清理日志.bat`
7. 点击完成

## 9. 数据库备份

### 方法一：管理后台（推荐）
1. 本机访问 http://127.0.0.1:3000
2. 切换到「🔧 管理」标签页
3. 管理员登录后点击「💾 备份数据库」
4. 备份文件保存在 `db_backup\` 目录，文件名包含日期时间戳

### 方法二：API 接口
```bash
curl -X POST http://127.0.0.1:3000/api/admin/backup \
  -H "Authorization: Bearer <管理员Token>"
```

### 自动备份
后台定时任务每天凌晨3:00自动备份数据库到 `db_backup\` 目录。

## 10. 向量库重建

当修改/新增/删除 `lagrange_docs` 文件夹中的文档后，需要重建向量索引：

### 方法一：API 接口
```bash
curl -X POST http://127.0.0.1:3000/api/rebuild-index
```

### 方法二：重启程序
每次程序启动时，如果检测到向量库为空，会自动构建。

## 12. 常见问题

### Q: 启动时提示「DEEPSEEK_API_KEY 未配置」
A: 检查项目根目录是否有 `.env` 文件，确认 `DEEPSEEK_API_KEY` 已正确填写。

### Q: 首次启动很慢
A: 首次启动需要下载嵌入模型（`sentence-transformers`），约 500MB，请耐心等待。后续启动无需重新下载。

### Q: 手机无法访问
A: 检查：
1. 手机和电脑连接同一WiFi
2. Windows防火墙是否拦截（临时关闭测试）
3. 使用正确内网IP（`ipconfig` 查看）

### Q: AI回复不准确
A: 确保 `lagrange_docs` 文件夹中有相关游戏资料文档，AI仅基于本地资料库作答。

### Q: Token不够用
A: 联系本机管理员在后台充值，或注册新账号获取10,000免费Token。
