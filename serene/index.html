战 斗 公 式
核心伤害公式 — 严格遵守《战斗机制.txt》§1.1.1
能量伤害：
Dmg = (Base + Tech + Strategy − Base × Shield%) × TUNE
// TUNE = 1.3（固定调校系数）| 护盾 ≥ 100%时免疫能量伤害

物理伤害（破防）：
Dmg = (Base + Tech + Strategy) × TUNE − Armor
// AfterArmor > 0 时生效

物理伤害（不破防）：
Dmg = (Base + Tech + Strategy) / 10 × TUNE
// 10%保底伤害

系统伤害：
Dmg = (Base + Tech + Strategy) × TUNE × SysCoeff
// SysCoeff: 主武器=1.25 | 机库=1.5 | 指挥=3.0

伤害分配： AttackableTargets = ⌊Total / 2.5⌋ | 维修公式： RepairDPM / 60 × (1 + Armor × 0.0025) ≤ 150%
// 1物理护甲 = 0.25%维修加成（150%上限）| 系统HP比: 主武器12% 机库10% 指挥8% 动力6%
